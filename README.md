## 🎮 遊戲規則

### 1. 任務目標與計分系統
*   **基礎挑戰**：連續通過 **8 個任務** 即可成功解除威脅，獲得基礎總分 100 分。
*   **單題分值**：前 8 題每題價值 12.5 分。
*   **魔王紅利**：若前 8 題全對且生命值尚存，將觸發隱藏的「魔王挑戰題」，答對可再加 50 分（最高總分可達 150 分）。
*   **補考機制**：若該題答錯或超時，進入補考模式後該題得分將會 **折半** 計算。

### 2. 防禦能量 (HP)
*   **初始生命**：你擁有 3 顆心 (❤️❤️❤️)。
*   **扣血機制**：只要「答錯」或「60 秒倒數結束」，都會扣除 1 顆心。
*   **任務失敗**：若 3 顆心全部扣完，炸彈將會引爆，遊戲立即結束。

### 3. 拆彈時限
*   **黃金 60 秒**：每一題只有 60 秒的時間思考與輸入答案。
*   **緊急警報**：當時間剩下 **最後 10 秒** 時，計時器會變紅並開始震動，提醒你加快速度！

### 4. 任務難度梯度
拆彈任務將依照下列順序出現，挑戰你的腦力極限：
*   **Level 1-2**：四位數大數加法與減法。
*   **Level 3-4**：四年級四則混合運算（含小括號）。
*   **Level 5-7**：生活單位換算（公斤/公克、公里/公尺、公升/毫升）。
*   **Level 8**：面積計算應用題（長方形面積）。
*   **Final Boss**：高難度進階混合運算邏輯。

## 🌟 遊戲特色

*   **沉浸式情境**：採用深色科幻風格介面，搭配動態震動回饋與生命值系統。
*   **紙筆建議系統**：新增行前溫馨提醒，培養學生動筆計算的良好習慣，降低心算錯誤率。
*   **智能題目生成**：內建記憶機制，確保短時間內不會出現重複題目。
*   **詳細結算報告**：遊戲結束後提供清單，詳列正確答案與玩家輸入，方便檢討錯誤。
*   **固定佈局優化**：專業 CSS 設計，確保在各種螢幕尺寸下遊戲面板皆能完美居中且不位移。
